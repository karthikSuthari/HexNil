================================================================================
                    MODULE 1: BATTERY HEALTH & DEGRADATION ANALYSIS
================================================================================

Purpose: Detect long-term battery wear before devices reach users.

Implementation Files:
- Manager: BatteryHealthManager.java
- Model: BatteryHealth.java
- DAO: BatteryHealthDao.java
- UI: HealthFragment.java

FEATURES:

1.1 Real Battery Health Estimation
    - Goes beyond Android's basic percentage
    - Uses charge counter data (BATTERY_PROPERTY_CHARGE_COUNTER)
    - Calculates actual mAh capacity vs design capacity
    - Formula: healthPct = (currentCapacity / designCapacity) * 100

1.2 Capacity Fade Tracking
    - Monitors design capacity vs actual capacity over time
    - Tracks capacity fade percentage: capacityFade = 100 - healthPct
    - Records estimatedCapacityMah from discharge cycles
    - Uses 72-hour discharge window for capacity estimation

1.3 Cycle Count Estimation
    - Calculates charge cycle equivalents from total charge/discharge
    - Formula: cycleEquivalents = totalChargeAccumulated / designCapacity
    - Tracks both partial and full cycles
    - 7-day rolling window for cycle calculation

1.4 Battery Aging Model
    - Degradation rate per month (fadePerMonth)
    - Degradation per 100 cycles (fadePer100Cycles)
    - Degradation trend classification: "stable", "gradual", "accelerating"
    - Predicted End-of-Life (EOL) in months when health drops below 80%

1.5 Early Detection of Abnormal Degradation
    - hasAbnormalWear: Flags when health < 80% or degradation > 5%/month
    - hasAbnormalAging: Flags when fade > 3% per 100 cycles
    - hasSwellingRisk: High temp during non-charging indicates swelling
    - hasCalibrationIssue: >10% mismatch between reported and actual level

1.6 Supplier/Batch Quality Tracking
    - Stores batteryModel, manufacturer, batchId
    - Calculates supplierAverageHealth across all devices
    - Calculates batchAverageHealth for batch comparison
    - Enables OEM to catch bad battery batches

SCORING SYSTEM:
- capacityScore: Based on health percentage (0-100)
- resistanceScore: Based on internal resistance (60-100)
- cycleScore: Based on cycle count vs 800 cycle baseline (0-100)
- overallScore: (capacityScore * 0.6) + (cycleScore * 0.3) + (resistanceScore * 0.1)

OEM VALUE:
- Catch bad battery batches early
- Validate supplier quality
- Predict warranty risks
- Data-driven supplier negotiations

4.1 App-Wise Battery Drain Ranking
    - Collects per-app usage via UsageStatsManager
    - Computes drainScore per app:

    - Ranks top 5 apps by contribution
    - Calculates contributionPct for each app

    - Separates system apps from user-installed

    - Calculates wakelock contribution to drain

4.4 Network Drain Analysis
    - networkType: "mobile", "wifi", "none"
    - networkDrainEstimate: 40% of drain for mobile, 20% for wifi

4.5 Screen-On vs Screen-Off Drain Analysis
    - Separate tracking for screenOn events
    - Calculates screenOnTime per drain event
    - displayDrainEstimate: (brightness/255) * drainRate
    - cpuDrainEstimate: (cpuLoad/100) * drainRate

DRAIN EVENT CLASSIFICATION:
- drainType: "heavy", "normal", "idle", "standby"
- drainCategory: "display", "system", "idle"
- expectedDrain vs actual (anomaly detection)

================================================================================
                         ANDROID SYSTEM APIs USED
================================================================================

1. BatteryManager API
   ─────────────────────────────────────────────────────────────────────────────
   Location: android.os.BatteryManager
   Used in: BatteryDataCollector.java, BatteryReceiver.java, BatteryMonitorService.java
   
   Data Retrieved:
   - EXTRA_LEVEL: Battery percentage (0-100)
   - EXTRA_SCALE: Maximum battery level
   - EXTRA_STATUS: Charging/Discharging/Full/Not charging
   - EXTRA_HEALTH: Good/Overheat/Dead/Over voltage/Unspecified failure
   - EXTRA_PLUGGED: AC/USB/Wireless charging source
   - EXTRA_VOLTAGE: Battery voltage in millivolts
   - EXTRA_TEMPERATURE: Battery temperature in tenths of °C
   - EXTRA_TECHNOLOGY: Battery chemistry (Li-ion, etc.)
   - BATTERY_PROPERTY_CHARGE_COUNTER: Remaining capacity in microampere-hours
   - BATTERY_PROPERTY_CURRENT_NOW: Instantaneous current in microamperes
   - BATTERY_PROPERTY_CURRENT_AVERAGE: Average current in microamperes
   - BATTERY_PROPERTY_CAPACITY: Remaining capacity percentage
   - BATTERY_PROPERTY_ENERGY_COUNTER: Remaining energy in nanowatt-hours

2. UsageStatsManager API
   ─────────────────────────────────────────────────────────────────────────────
   Location: android.app.usage.UsageStatsManager
   Used in: AppUsageCollector.java
   Permission Required: PACKAGE_USAGE_STATS (special permission)
   
   Data Retrieved:
   - Per-app foreground time
   - Per-app total time in foreground
   - Usage statistics intervals (daily/weekly/monthly)

3. PowerManager API
   ─────────────────────────────────────────────────────────────────────────────
   Location: android.os.PowerManager
   Used in: BatteryMonitorService.java, BatteryDataCollector.java
   
   Features Used:
   - PARTIAL_WAKE_LOCK: Keep CPU running for background monitoring
   - isDeviceIdleMode(): Check if device is in Doze mode
   - isInteractive(): Check if screen is on
   - isPowerSaveMode(): Check if battery saver is active

4. ActivityManager API
   ─────────────────────────────────────────────────────────────────────────────
   Location: android.app.ActivityManager
   Used in: BatteryDataCollector.java
   
   Data Retrieved:
   - Running processes
   - Memory info
   - Foreground app detection

5. ConnectivityManager API
   ─────────────────────────────────────────────────────────────────────────────
   Location: android.net.ConnectivityManager
   Used in: BatteryDataCollector.java
   
   Data Retrieved:
   - Network type (WiFi/Mobile/None)
   - Network state

6. Intent Broadcasts (System Events)
   ─────────────────────────────────────────────────────────────────────────────
   Used in: BatteryReceiver.java, BatteryMonitorService.java
   
   Broadcasts Monitored:
   - ACTION_BATTERY_CHANGED: Any battery state change
   - ACTION_POWER_CONNECTED: Charger plugged in
   - ACTION_POWER_DISCONNECTED: Charger unplugged
   - ACTION_BATTERY_LOW: Battery below 15%
   - ACTION_BATTERY_OKAY: Battery above 15%
   - ACTION_BOOT_COMPLETED: Device boot (to restart service)
